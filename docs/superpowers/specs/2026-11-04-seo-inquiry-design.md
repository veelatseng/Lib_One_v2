# Lib One SEO 與靜態諮詢修正

使用者已核准 Veela 精簡提案的四項問題及兩項內容補強，要求完成後提交 PR。此次範圍僅 `veelatseng/Lib_One_v2`，不部署或合併，也不修改另一個測試站。

## 已確認的限制

- 使用者確認為純靜態網站，沒有收件後端。因此表單改為 Email 草稿與複製需求，明確要求使用者自行送出；不呼叫未知 API、不宣稱已收件、不傳送測試 Email。
- lib-one.com 位於 Cloudflare 後方；repo 沒有現行主機設定。提供靜態資產 `_redirects` 與可加入現有 Cloudflare Single Redirect 的規則 JSON。HTTPS 是邊緣設定，須於維護端套用；PR 不代表線上設定已變更。
- 保留產品圖片、現有互動、相機取捨、規格數值及服務聯絡地址；新選型內容僅根據既有產品頁。

## 修改設計

1. 15 頁採 `https://lib-one.com/` 與無副檔名 canonical；站內連結及 JavaScript 產生的連結一致；舊 HTML 網址永久轉址，查詢參數及錨點保持可用。
2. 提供 15 頁 sitemap 並由 robots.txt 宣告。結構化資料使用一致的 Organization、Brand、WebSite 識別、完整 URL、圖片網址及公司關係；Product 描述與畫面一致，不虛構價格或評分。
3. 修正桌上型空間座位預約機介紹。首頁增加簡短公司與品牌關係說明。所有產品有帶產品識別的諮詢入口；導航連聯絡表單並保留直接 Email。
4. 補 HyPass 選項；從產品連結只預選已知 ID。表單使用原生必填與 Email 驗證；純前端產生 Email 主旨／內容。失敗時保留輸入，提供可手動複製的文字；不把草稿或複製當成寄信成功。
5. 館員工作站、RFID 工作站及桌上型自助借還書機各補實際選型表、導入條件與 3–5 題問答；沒有來源的能力不補寫。新樣式沿用 SCSS 色彩與排版，編譯 CSS 一併提交。
6. README 說明本地預覽、靜態發布目錄、主機轉址套用步驟及 Email 需使用者送出的限制。

## 驗收

先建立會失敗的行為測試，覆蓋 sitemap／canonical／內部網址一致、13 產品諮詢、HyPass 預選、文案／schema 一致及 Email 內容安全編碼。修正後驗證靜態建置、舊路徑／未知路徑、本機桌機與手機頁面、產品比較／問答與聯絡表單。Email 只測草稿與複製，不測真實送件。HTTPS 規則另以公開驗收命令記錄待套用狀態。
