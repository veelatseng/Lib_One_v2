Desktop Space Kiosk

桌上型空間座位預約機

讓讀者查詢、預約並完成座位與討論室報到

座位、討論室與設備狀態集中在同一畫面，讀者可現場完成查詢、預約與報到，逾時席位也會自動釋出。
館方透過單一介面掌握空間使用，管理更清楚。
桌上型螢幕可調整橫直方向，配合現場空間選擇顯示方式。模組化架構便於零件更換與現場檢修。
機體結構底材採用鋁合金及 SECC 電鍍鋅鋼板，外層施以工業級烤漆進行雙重阻絕防護。

主要功能

CORE FUNCTIONS

  1. 座位、討論室與設備即時查詢及預約。
  2. 借閱證、條碼或 App QR Code 驗證報到。
  3. 預約時段、資格、次數與黑名單規則。
  4. 逾時未報到自動釋出及使用提醒。
  5. 使用率、熱門時段與異常紀錄報表。
